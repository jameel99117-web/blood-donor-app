# Blood Donor Finder App

A mobile app that connects blood donors with people/hospitals in need, helping users find nearby donors quickly during emergencies.

## Features

- 🔍 Search for blood donors by blood group and location
- 📍 Location-based donor matching
- 👤 User registration as donor/recipient
- 📞 Direct contact with available donors
- 🔔 Notifications for urgent blood requests
- 📱 Cross-platform (iOS & Android) via Expo

## Installation

1. Clone the repository
```bash
   git clone https://github.com/HxnDev/Portfolio.git
   cd blood-donor-app
```

2. Install dependencies
```bash
   npm install
```

3. Start the app
```bash
   npx expo start
```
